========================================
  KALENI CATERING SERVICES - SERVER INFORMATION
========================================

PORT CONFIGURATION:
-------------------
Main Site (Customer):  http://localhost:8003
Admin Panel:           http://localhost:8004/{your ADMIN_PATH from .env}/login

STARTUP FILES:
--------------
START_BOTH.bat    - Starts both servers (RECOMMENDED)
START.bat         - Starts main site only (port 8003)
START_ADMIN.bat   - Starts admin panel only (port 8004)

ADMIN CREDENTIALS:
------------------
Email:    kalenilucas061@gmail.com
Password: printed once to the terminal when `php artisan db:seed --class=AdminUserSeeder`
          runs. There is no fixed default password. Two-factor authentication is required
          on first login.

QUICK START:
------------
1. Double-click START_BOTH.bat
2. Wait for both servers to start
3. Open browser:
   - Customer site: http://localhost:8003
   - Admin panel: http://localhost:8004/{your ADMIN_PATH from .env}/login

STOPPING SERVERS:
-----------------
Press Ctrl+C in each server window, or simply close the windows.
